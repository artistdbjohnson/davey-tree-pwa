# davey-tree-pwa

Independent design study of The Davey Tree Expert Company marketing site. **Not affiliated** with Davey Tree.

- Motionsites seed: `mythic-naturecore`
- Exact public copy and forest-green identity from davey.com
- SERVPRO/Budget/Roto liquid-glass craft bar: semi-opaque nav, cards, trust chips, ~5px radii, phone-first chrome, sticky consultation dock
- EN|PT chrome and persisted dark|light (marketing body stays English)
- Compositor-only scroll/parallax, rAF-owned, gated for reduced motion, hidden tabs, and offscreen heroes
- Installable PWA (manifest + service worker)
- Mock consultation form only — no real booking or payment
